## 1. Executive Summary for the Team

This branch implements the **Security Scanner Service** on port `8002` for **ConsensusDev**. It provides deterministic, containerized static analysis (SAST), Infrastructure-as-Code (IaC) checks, and dependency vulnerability (CVE) scanning. 

Findings generated by this service are sent back to the **Gateway (Ahmed)** and fed into the **AI Engine (Ahmed/Medhat)** as structured security evidence to decide whether a PR is safe to merge.

## 2. Service Details & API Contract

### Network Configuration
- **Host / Port:** `http://localhost:8002` (or `http://scanners:8002` in Docker network)
- **Base Endpoints:**
  - `GET /` — Service metadata and operational status.
  - `GET /health` — Health check endpoint for Gateway discovery.
  - `POST /scan` — Main security analysis endpoint.

### `POST /scan` Contract

#### Request Payload:
```json
{
  "diff": "string (unified git diff)"
}
```

#### Response Payload (Dual-Compatible Format):
```json
{
  "status": "PASS",
  "vulnerabilities": 0,
  "vulnerabilities_count": 0,
  "critical_issues": [],
  "findings": [],
  "details": [],
  "summary": "Security scan passed: no vulnerabilities or insecure patterns detected in diff."
}
```

#### Response Example on Vulnerable Diff:
```json
{
  "status": "FAIL",
  "vulnerabilities": 2,
  "vulnerabilities_count": 2,
  "critical_issues": [
    "[CRITICAL] Hardcoded AWS Access Key in config.py:1",
    "[CRITICAL] Potential SQL Injection via String Formatting in db.py:11"
  ],
  "findings": [
    {
      "rule_id": "SEC-001",
      "title": "Hardcoded AWS Access Key",
      "severity": "CRITICAL",
      "description": "Detected hardcoded AWS Access Key ID. Hardcoded credentials can lead to unauthorized cloud infrastructure access.",
      "file": "config.py",
      "line": 1,
      "snippet": "AWS_ACCESS_KEY_ID = 'AKIAIOSFODNN7EXAMPLE'",
      "recommendation": "Use environment variables or a secrets manager (e.g., AWS Secrets Manager, HashiCorp Vault)."
    }
  ],
  "details": [ ... ],
  "summary": "Security scan failed: found 2 security issue(s) (2 high/critical)."
}
```

## 4. Security Rules & Capabilities

### SAST & Secrets Detection:
- **`SEC-001`**: Hardcoded AWS Access Keys (`AKIA...`, `ASIA...`)
- **`SEC-002`**: Embedded Cryptographic Private Keys (`-----BEGIN PRIVATE KEY-----`)
- **`SEC-003`**: Hardcoded GitHub Personal Access Tokens (`ghp_...`, `github_pat_...`)
- **`SEC-004`**: Plaintext credentials, passwords, and API key assignments
- **`SEC-005`**: SQL Injection via f-strings, format strings, or direct string concatenation
- **`SEC-006`**: Dangerous Command Injection (`os.system`, `subprocess(..., shell=True)`)
- **`SEC-007`**: Dynamic Code Execution (`eval()`, `exec()`)
- **`SEC-008`**: Unsafe Object Deserialization (`pickle.loads`, `yaml.load` without SafeLoader)
- **`SEC-009`**: Disabled TLS/SSL verification (`verify=False`, `NODE_TLS_REJECT_UNAUTHORIZED=0`)

### IaC (Infrastructure as Code) Detection:
- **`IAC-001`**: Overly permissive security group ingress (`0.0.0.0/0`)
- **`IAC-002`**: Public S3 bucket ACL configurations (`public-read`, `public-read-write`)
- **`IAC-003`**: Wildcard IAM Action permissions (`Action: *` with `Effect: Allow`)

### Dependency Vulnerabilities (Trivy):
- Scans `requirements.txt` and `package.json` for known vulnerable package versions and attaches CVE identifiers (e.g. `CVE-2023-32681` in `requests`, `CVE-2023-45803` in `urllib3`, `CVE-2021-23337` in `lodash`, `CVE-2023-45857` in `axios`).

## 5. How the Team Can Run & Verify

### Running the Service Locally
```powershell
# From the repository root:
uvicorn scanners.app:app --reload --port 8002
```

### Running the Test Suite
```powershell
python -m unittest tests/test_scanner.py
```

### Testing with `curl`

**1. Health Check:**
```powershell
curl http://127.0.0.1:8002/health
```

**2. Clean Diff (Pass):**
```powershell
curl -X POST http://127.0.0.1:8002/scan `
  -H "Content-Type: application/json" `
  -d "{\"diff\": \"+ def add(a, b):\\n+     return a + b\"}"
```

**3. Vulnerable Diff (Fail):**
```powershell
curl -X POST http://127.0.0.1:8002/scan `
  -H "Content-Type: application/json" `
  -d "{\"diff\": \"+ AWS_SECRET = 'AKIAIOSFODNN7EXAMPLE'\\n+ query = f'SELECT * FROM users WHERE id = {user_id}'\"}"
```
